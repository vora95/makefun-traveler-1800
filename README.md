A small program that writes one short text (195 characters) to `/output/entry.txt`: a single original sentence explaining the modern internet to a time traveler from 1800 — a road from your door to every house on earth, where a letter runs faster than any horse and comes back with a page from the great library or a word from a friend, before your supper cools.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
